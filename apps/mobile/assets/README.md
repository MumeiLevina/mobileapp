# Mori app icon assets

Generated with the built-in image generation tool for the Phase G native build configuration.

The source prompt requested a centered, text-free symbol combining a sheltered sprout and crescent-shaped embrace, with a warm cream, forest green and muted terracotta palette. It explicitly excluded faces, hearts, medical crosses, brain icons, chatbot bubbles, gradients, shadows and watermarks. `adaptive-icon.png` is the same mark with a transparent background and additional safe area for Android masks.
